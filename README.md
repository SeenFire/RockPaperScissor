# RockPaperScissor
For this project, i will be attempting to create the Rock Paper Scissors game which will be played in the console.
I will write a function to generate a random number between 0 and 1.
if the number is 0.33 or less, the choice is "rock".
else if the number is 0.66 or less, the choice is "paper".
otherise, if the number is greater than 0.66, the choice is "scissors".
at the end, i will return the choice.
